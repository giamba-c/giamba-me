# Giamba.me - Personal Brand Site

A minimalist, high-performance web interface inspired by the **macOS Spotlight** search bar.

## 🚀 Vision
The goal of this project is to create a digital presence that is:
- **Ultra-minimalist:** Zero distractions, focus on content.
- **AI-Friendly:** Structured data for seamless information retrieval by AI agents.
- **Performant:** Built with modern web standards for instant loading.

## 🛠 Tech Stack
- **Framework:** Astro (planned)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## 📂 Structure
- **Spotlight Bar:** Central command for site navigation.
- **Core Icons:** Quick access to Bio, Works, Contact, and Socials.
